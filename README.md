# PSPerfume

PSPerfume is a full-stack perfume e-commerce web application built with Next.js, Node.js, Express, and MongoDB.

## Features

* Browse and search perfumes
* View product details
* Add products to cart
* Login and signup
* User profile and order history
* Product and order management

## Authentication

Clerk is used for the login and signup system. I used Clerk because it provides secure, ready-to-use authentication and makes user registration, login, and account management easier to implement.

## Technologies

* Next.js
* React
* Node.js
* Express.js
* MongoDB
* Mongoose
* Clerk

## Run Locally

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```
